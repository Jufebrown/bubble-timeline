# bubble-timeline

This project tracks important events in the AI bubble. Not real AI, but large language models (LLMs). I thought it would be interesting to visualize the amount and type of hype around model releases and funding rounds.

## Timeline Event Sources

[Timeline of OpenAI](https://timelines.issarice.com/wiki/Timeline_of_OpenAI).

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
